# Cloud disaster recovery project

Start with [the live demonstration guide](live_demo/README.md) and [the project and file report](PROJECT_REPORT.md).

The `live_demo/` folder contains a focused, real AWS EC2/Route 53 failover design. It requires a valid AWS account, deployment, a domain or delegated subdomain for normal DNS, and an actual test. Its infrastructure is not automatically live just because the files exist. AWS resources incur charges.

The other files are earlier prototypes and simulations. They are retained for reference; their simulated values are not measured AWS results, and they do not prove complete database failover or production readiness.
